## 📌 Page Structure & Navigation

1. **Login Page (Starting View):**
   - User enters Name & Password.
   - User selects role: **Joiner (Attendee)** or **Host (Organizer)**.
   - Clicking Login unlocks the platform.

2. **Browse Events Tab:**
   - Displays all scheduled webinars in a clean CSS Grid layout.
   - Live Search bar (by event title) and Category dropdown.
   - **Joiner:** Can register for events or cancel their seat.
   - **Host:** Can delete events.

3. **Host New Event Tab (Host Only):**
   - Simple HTML Form with Title, Category, Date, Time, Host Name, Seats, and Description.
   - On submission, the event is immediately published.

4. **Manage & Registrations Tab:**
   - Full HTML Table (`<thead>`, `<tbody>`, `<tfoot>`) showing all events, capacities, and bookings.
   - Displays real-time total bookings.
